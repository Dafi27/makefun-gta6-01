Palmera Bay — an original 3D open-world crime game in the spirit of GTA 6. Play as Mara Voss, ex-getaway driver, back in the sun-soaked coastal city of Palmera Bay: explore the city on foot and by car, steal cars, outrun the police under a 5-star wanted system, fight, and run five story jobs for Dante's crew. Traffic, pedestrians, combat, a live minimap HUD, a start screen and a save — all running offline from static files. Built by an AI agent for the make.fun gta6-01 bounty ($1,666 in USDC).

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 to play. Or build the submission output with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
